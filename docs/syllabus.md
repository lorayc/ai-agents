# AI Agents Workshop Syllabus

**UCLA Master of Quantitative Economics — Spring 2026**

## Workshop description

This four-session workshop provides a rigorous, hands-on introduction to the
design and deployment of AI-powered agents. Participants progress from large
language model tooling to production-minded multi-agent systems through
economic and financial research examples.

Each session combines conceptual instruction, coding exercises, and
collaborative problem-solving.

## Learning objectives

After completing the workshop, participants should be able to:

- Explain the foundations of AI agents and their relationship to modern large
  language models.
- Design, implement, and test a single-agent system that interacts with
  external data sources and APIs.
- Apply retrieval-augmented generation to document analysis.
- Architect coordinated multi-agent workflows for complex analytical tasks.
- Evaluate reliability, cost, safety, and observability in production systems.
- Design a functional agent or multi-agent system as a capstone project.

## Sessions

### 1. Foundations and single agents

Define what an agent is, work with APIs and structured outputs, and build a
data agent that uses tools to retrieve economic data.

### 2. RAG and document intelligence

Build a vector store and a retrieval-augmented analyst that grounds its
answers in economic and financial documents.

### 3. Multi-agent orchestration

Decompose a macroeconomic research workflow into specialized roles, test
their handoffs, and construct a comparison index from Federal Reserve Beige
Book releases.

### 4. MCP, deployment, and production

Study MCP-style tool interfaces and production concerns including
specification-driven development, guardrails, evaluation, observability, and
cost control.

## Capstone

Design and build a functional AI agent or multi-agent system. The project
should identify its intended user and decision, define its data and tools,
make system boundaries explicit, and describe how quality and safety will be
evaluated.

## Recommended background

- Comfort with Python data structures, functions, and libraries such as
  pandas.
- Prior exposure to econometrics or data analysis.
- Familiarity with basic financial concepts.

Participants without this background can still take part but may need
additional time to review Python and quantitative methods.

## Technology

Participants need a laptop with Python 3.11 or newer. Sessions 1 and 2 require
personal Anthropic and FRED API keys. See the repository
[setup instructions](../README.md#quick-start) before beginning.

## Academic integrity

Collaboration is encouraged. Participants should represent their own analysis
and system-design decisions in the capstone project.
